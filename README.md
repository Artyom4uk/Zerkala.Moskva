# Зеркала.Москва

Сайт-каталог и система оформления заказов зеркал только в пределах Москвы. Московская область не обслуживается.

## Текущий этап

Это frontend-MVP для GitHub Pages:

- адаптивный каталог;
- наборы **Стандарт** и **Стандарт+**;
- режим **Нестандарт** с шириной и высотой;
- визуальный предпросмотр пропорций;
- форма оформления заказа;
- мини-чек с уникальным номером;
- подготовка к печати / сохранению чека через системный диалог печати;
- московское ограничение на уровне интерфейса.

Цены пока намеренно не зафиксированы. После получения правил от владельца они будут вынесены в отдельную конфигурацию.

## План backend

После согласования бизнес-правил:

`GitHub Pages → Cloudflare Worker → D1 → MAX Bot API`

Backend будет принимать заказ, сохранять его в базе и отправлять владельцу структурированное уведомление в MAX. Секреты и токены не должны находиться в frontend-коде.

## Важно

Frontend сейчас работает в демонстрационном режиме: оформление показывает чек в браузере и не отправляет персональные данные на сервер. Реальный приём заказов подключается только после добавления защищённого backend.
